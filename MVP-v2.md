# Latest Proposal 106 preview

The location-search and negotiation update is in [`mvp/proposal106-v2/`](mvp/proposal106-v2/README.md).

From this repository's root:

```sh
python3 -m http.server 4174 --bind 127.0.0.1 --directory mvp/proposal106-v2
```

Open http://127.0.0.1:4174/. If occupied, use another port. This is a local preview; teammates run it on their own machines.

The previous six-stage version remains in `mvp/proposal106/`. Existing team models and the earlier MVP remain unchanged. See the new version's README for validation and review limitations.
